# Customer Uploads Help

This page explains how to use the customer upload interface for attaching photos, receipts, and documents to your open claims.

## What claims can I upload attachments to?

You can upload attachments only to claims with status **SUBMITTED** or **IN_REVIEW**. These are considered "open" claims. Attachments cannot be added to claims that are approved, paid, denied, or otherwise closed.

## Which file types are allowed?

You can upload files in these formats only:
- JPEG (.jpg, .jpeg)
- PNG (.png)
- PDF (.pdf)

The system detects file types by scanning the file contents to ensure safety, so file extensions alone do not guarantee acceptance.

## Size and quantity limits

- Maximum size: 10 MB per file
- Maximum files: 20 attachments per claim

Files exceeding these limits will not be uploaded.

## How do I upload files?

1. Select an allowed file from your device by clicking the **Select file** button.
2. Click the **Upload file** button to add the file to your claim.

You can repeat this up to the file limit.

## Viewing and downloading attachments

Once uploaded, your attachments will be listed in the claim's attachments section. You can click on an attachment to download it.

## Sensitive information warning

Please be aware that the photos and receipts you upload may contain sensitive personal information. Handle these documents carefully.

## Troubleshooting and errors

If you encounter errors during upload, please check:
- The claim is open (SUBMITTED or IN_REVIEW)
- Your file type is JPEG, PNG, or PDF
- Your file size is not more than 10 MB
- You have not exceeded the limit of 20 attachments per claim

If problems persist, contact customer support for assistance.
